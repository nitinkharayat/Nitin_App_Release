## 📦 Downloads

APK files are provided through this repository for testing, personal use, and evaluation.

Before installing an APK, make sure you understand where it came from and that you trust the release.

### Installation

1. Open the **Releases** section of this repository.
2. Select the application and version you want.
3. Download the `.apk` file.
4. Transfer/open it on your Android device.
5. Install the application.

Android may require permission to install applications from unknown sources.
